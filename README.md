### 1. Top-Paying Data Scientist Jobs
To identify the highest-paying roles, I filtered Data Scientist positions by average yearly salary and location, focusing on remote jobs. This query highlights the high paying opportunities in the field.

```sql
SELECT
    job_id AS "Job ID",
    job_title AS "Job Title",
    job_location AS "Location",
    job_schedule_type AS "Schedule Type",
    salary_year_avg AS "Average Salary (Yearly)",
    job_posted_date AS "Posted Date",
    company_dim.name AS "Company Name"
FROM
    job_postings_fact
LEFT JOIN
    company_dim ON job_postings_fact.company_id = company_dim.company_id
WHERE 
    job_title = 'Data Scientist' AND
    job_work_from_home = TRUE AND
    salary_year_avg IS NOT NULL 
ORDER BY
    salary_year_avg DESC
LIMIT 10;
```


### 💡 Here's top-Paying Remote Data Scientist Jobs Key Insights:
- **Remote Data Scientist roles can offer exceptionally high compensation**. The top-paying position offers an average annual salary of $375K, while the top 10 range from $185K to $375K, highlighting the strong earning potential of remote Data Science careers.
- **Compensation is concentrated among a small group of employers**. Algo Capital Group appears twice in the top 10, while Grammarly also appears twice, suggesting that some companies consistently offer highly competitive compensation for Data Scientist talent.
- **High-paying opportunities span different industries and employers**. Companies such as Cisco, Grammarly, Tomorrow.io, Mineral.ai, Storm2, and Smith Hanley Associates appear among the highest-paying postings, showing that lucrative Data Scientist roles are available across technology, AI, finance, and specialized industries.

### 2. Skills for Top Paying Jobs
To understand what skills are required for the top-paying jobs, I joined the job postings with the skills data, providing insights into what employers value for high-compensation roles.

```sql
WITH top_paying_jobs AS (
    SELECT
        job_id AS "Job ID",
        job_title AS "Job Title",
        salary_year_avg AS "Average Salary (Yearly)",
        job_posted_date AS "Posted Date",
        company_dim.name AS "Company Name"
    FROM
        job_postings_fact
    LEFT JOIN
        company_dim ON job_postings_fact.company_id = company_dim.company_id
    WHERE 
        job_title = 'Data Scientist' AND
        job_work_from_home = TRUE AND
        salary_year_avg IS NOT NULL 
    ORDER BY
        salary_year_avg DESC
    LIMIT 10
) 

SELECT 
    top_paying_jobs.*,
    skills AS "Required Skills"
FROM top_paying_jobs
INNER JOIN skills_job_dim ON top_paying_jobs."Job ID" = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id;
```

### 3. In-Demand Skills for Data Scientist

This query helped identify the skills most frequently requested in job postings, directing focus to areas with high demand.

```sql
SELECT
    skills_dim.skills AS "Skill",
    COUNT(skills_job_dim.job_id) AS "Demand Count"
FROM job_postings_fact 
INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
WHERE job_postings_fact.job_title ='Data Scientist' 
    AND job_work_from_home = 'True'
GROUP BY 
    skills_dim.skills
ORDER BY
    "Demand Count" DESC
LIMIT 5;
```
### 📊 Most In-Demand Data Science Skills

The analysis shows that **Python is the most in-demand skill**, appearing in **2,558 job postings**, followed by **SQL (1,833)** and **R (1,148)**. Cloud and visualization skills also show strong demand, with **AWS (697)** and **Tableau (634)** rounding out the top five.

### 💡 Key Insight

**Python and SQL clearly dominate the demand for Data Science roles**, making them essential skills for aspiring Data Scientists. Meanwhile, **R, AWS, and Tableau** complement these core skills by supporting statistical analysis, cloud computing, and data visualization.

### 4. Skills Based on Salary
Exploring the average salaries associated with different skills revealed which skills are the highest paying.

```sql
SELECT
    skills_dim.skills AS "Skill",
    ROUND(AVG(job_postings_fact.salary_year_avg),0) AS "Average Salary (Yearly)"
FROM job_postings_fact 
INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
WHERE job_postings_fact.job_title ='Data Scientist' 
    AND salary_year_avg IS NOT NULL
    AND job_work_from_home = 'True'
GROUP BY 
    skills_dim.skills
ORDER BY
    "Average Salary (Yearly)" DESC
LIMIT 25;
```

### 5. Most Optimal Skills to Learn

Combining insights from demand and salary data, this query aimed to pinpoint skills that are both in high demand and have high salaries, offering a strategic focus for skill development.

```sql
SELECT 
    skills_dim.skill_id,
    skills_dim.skills AS "Skills",
    COUNT(skills_job_dim.job_id) AS "Demand Count",
    ROUND(AVG(job_postings_fact.salary_year_avg), 0) AS "Average Salary"
FROM job_postings_fact
INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
WHERE
    job_title_short = 'Data Scientist'
    AND salary_year_avg IS NOT NULL
    AND job_work_from_home = True
GROUP BY
    skills_dim.skill_id
ORDER BY
    "Average Salary" DESC,
    "Demand Count" DESC
LIMIT 25;
```

```sql

WITH skills_demand AS (
    SELECT
        skills_dim.skill_id,
        skills_dim.skills,
        COUNT(skills_job_dim.job_id) AS "Demand Count"
    FROM job_postings_fact 
    INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id

        AND job_work_from_home = 'True' 
        AND salary_year_avg IS NOT NULL
    GROUP BY 
        skills_dim.skill_id
), average_salary AS (
    SELECT
        skills_job_dim.skill_id,
        ROUND(AVG(job_postings_fact.salary_year_avg),0) AS "Average Salary (Yearly)"
    FROM job_postings_fact 
    INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
    INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
    WHERE 
        job_postings_fact.job_title ='Data Scientist' 
        AND salary_year_avg IS NOT NULL
        AND job_work_from_home = 'True'
    GROUP BY 
        skills_job_dim.skill_id
)

SELECT
    skills_demand.skill_id,
    skills_demand.skills AS "Skill",
    skills_demand."Demand Count",
    average_salary."Average Salary (Yearly)"
FROM 
    skills_demand
INNER JOIN average_salary ON skills_demand.skill_id = average_salary.skill_id
WHERE
    skills_demand."Demand Count" > 10
ORDER BY
    skills_demand."Demand Count" DESC,
    average_salary."Average Salary (Yearly)" DESC
LIMIT 25;
```
### 💡 Insight: Most Optimal Skills to Learn

Based on the analysis of remote Data Scientist positions with specified salaries, the following insights highlight the skills that provide the best balance between **job demand and earning potential**:

- **Python and SQL are the strongest foundational skills.** Python has the highest demand (**218 postings**) with an average salary of **$128,320**, while SQL follows with **179 postings** and **$126,643**. Their combination offers both strong employability and competitive salaries.

- **Tableau and AWS provide an attractive balance of demand and salary.** Tableau appears in **67 postings** with an average salary of **$134,177**, while AWS appears in **59 postings** with an average of **$131,488**.

- **Spark stands out as a high-value technical skill.** Although its demand is lower (**43 postings**), it is associated with an average salary of **$135,097**, making it particularly valuable for data engineering and large-scale data processing roles.

- **Specialized technical skills can command higher salaries despite lower demand.** Skills such as **Scala ($144,576)**, **Java ($142,325)**, and **Snowflake ($138,833)** have relatively fewer postings but offer some of the highest average salaries in the dataset.

- **The optimal learning strategy is to combine foundational and specialized skills.** A strong combination of **Python + SQL** can provide broad job opportunities, while adding skills such as **AWS, Tableau, Spark, or Snowflake** can increase specialization and potentially improve earning potential.
